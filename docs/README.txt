UPLOAD YOUR NABL DOCUMENTS HERE
================================
1. Save the current NABL certificate as a PDF named exactly:  nabl-certificate.pdf
2. Save the scope of accreditation as a PDF named exactly:    nabl-scope.pdf
3. Upload both into this /docs folder (cPanel → File Manager).
The "View / Download certificate" and "Scope" buttons appear automatically once the files exist.
Using an image instead of PDF? Upload e.g. nabl-certificate.jpg and change "certificate_file" in /data/nabl.json to "docs/nabl-certificate.jpg".
